# TODO Workflow

`docs/TODO.md` is the live backlog where humans record work for the project. It contains project tasks only; instructions and examples belong outside that file.

When handling a TODO:

1. preserve the human's intent;
2. improve wording, structure, context, and acceptance criteria when this makes the task clearer;
3. request clarification instead of guessing when ambiguity could materially change scope or behavior;
4. update the entry when work changes its status;
5. mark completed work with `[x]` and add a concise outcome or relevant path when useful;
6. do not silently delete completed entries unless a human requests cleanup.

Recommended forms:

```markdown
- [ ] Describe the intended outcome and important constraints.
- [x] Describe the completed outcome. See `path/to/result` when applicable.
```
