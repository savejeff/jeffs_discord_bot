# Test Fixtures

Discord-shaped numeric identifiers in this directory are synthetic fixtures. The repeated `100000000000000...` and `999999999999999999` patterns do not identify a real application, guild, channel, thread, role, user, message, or attachment.

Keep new identifiers visibly synthetic and define frequently reused values as named constants near the top of the relevant test module. Never copy identifiers from a live Discord payload into version control.
