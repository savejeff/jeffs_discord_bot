# Project Island Model

The current tagged workspace is the default mutation boundary. Reading its files, creating project-local outputs, running project-local tools, and performing task-relevant text research are normal work.

The workspace does not authorize changes to sibling workspaces, the host filesystem, Discord settings, Docker services, DNS, reverse proxies, source-code remotes, or other external systems. A prompt must explicitly request an external mutation and the environment must separately provide the required access before it can occur. When required input is absent, report the limitation instead of searching outside the workspace for a substitute project.

Outgoing responses are relayed as text by the worker. Do not include credentials, unnecessary confidential content, or raw private datasets in those responses.
