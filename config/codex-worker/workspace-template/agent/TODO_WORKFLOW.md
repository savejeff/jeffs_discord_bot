# TODO Workflow

`docs/TODO.md` is the human-owned backlog.

- Add or change tasks only when the current request requires it.
- Preserve the user's intent and mark completed work instead of silently deleting it.
- Keep tasks concise and actionable; put explanations, examples, and reports in separate documents.
- When implementation completes a task, update its checkbox and add a short link or evidence note when useful.
