# Utility Scripts

Store reusable workspace-specific helpers here. Give non-trivial scripts a module or function description, document their inputs and outputs, and keep generated data in `data/`, raw logs in `logs/`, or disposable intermediates in `tmp/`.

Python utilities must run through `scripts/.venv/bin/python`. Add their packages to `scripts/requirements.txt` before sourcing `scripts/activate_venv.sh` in a new workspace.
